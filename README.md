# Global Superstore Sales Analysis

## Overview
An interactive Power BI dashboard analysing global retail sales, profitability, product performance, and trends to support data-driven decision-making.

## Key Features
- Regional sales and profit analysis
- Product category performance
- Sales trends over time
- Interactive slicers and drill-down
- Matrices, bar charts, combo charts, and sparklines

## Tools & Skills
Power BI | Power Query | Data Visualisation | Business Intelligence
